# Optional device artwork

The editor can use a separately supplied local device-artwork package. That package is not included in this source snapshot. Unavailable devices are not offered for new projects; projects referencing missing artwork retain their identifiers and cannot silently export an incomplete frame.

See [asset provenance](../ASSET_PROVENANCE.md) and [third-party notices](../THIRD_PARTY_NOTICES.md) for distribution boundaries. A successful browser-code test does not certify an absent artwork package.
