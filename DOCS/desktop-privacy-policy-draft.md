# ScreenHello 桌面隐私政策草案

日期：2026-09-17。**这是待核实和发布的草案，不是已上线的商店隐私政策。** 运营主体、联系方式、正式 URL 和最终二进制网络验收尚未确定；不得把本文件直接标记为上架完成。

## 本地编辑与保存

ScreenHello 桌面版在设备上编辑图片、截图和项目，无需云账号。项目、草稿、预设与偏好使用本地存储；主动导出的图片及 `.screenhello` 文件保存到用户选择的位置。现有编辑流程不提供将图片上传到 ScreenHello 云端的功能。

自动草稿不能代替主动保存的项目文件。清理应用数据可能删除草稿、资料库与偏好；卸载是否保留数据取决于系统与安装渠道，应在最终安装包验收后提供各系统准确的清理步骤。主动导出的文件由用户在文件系统中删除。

## 系统权限

文件对话框用于选择输入与输出。屏幕捕获用于用户主动请求的截图；可以拒绝或在系统设置中撤销权限。剪贴板功能用于用户请求的粘贴或复制。权限声明不等于数据上传。

## 网络与第三方运行时

页面流量计数只覆盖编辑页面可观察的通道，不是整个程序、操作系统或运行时的网络审计。打开外部帮助或问题反馈页面时，相应网站按其自身政策处理访问数据；提交问题时请避免附带敏感图片、项目或系统信息。

Windows 版使用 Microsoft WebView2。Microsoft 文档说明运行时存在必要与可选诊断数据，且默认启用 SmartScreen 安全检查；这些机制的行为与 Windows 设置及实际运行时配置有关。请参阅 [WebView2 数据与隐私](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy)、[Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)。不能据此推断本地编辑图片已被上传，也不能以页面计数为零保证整个应用绝对没有联网。

macOS 使用系统 WKWebView，不能将 Windows 的运行时说明直接作为 macOS 的数据收集申报。最终商店隐私问卷需按各平台最终包、依赖和实测分别填写。
