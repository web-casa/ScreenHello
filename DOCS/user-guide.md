# 用户功能指南

## 界面语言与安全恢复

在“帮助”菜单打开任一帮助主题，可选择简体中文或 English；独立站会在当前设备记住选择，不上传偏好。项目名、图片、文字标注和旧存档不会随界面语言改变；表情名称与搜索词库沿用 Emoji Mart 英文数据。

遇到“原草稿已保留，本次会话已暂停自动保存”时，可以继续编辑和导出，请通过文件菜单保存项目文件。旧草稿不会被本会话自动覆盖或清空；重新打开页面可再次尝试恢复。若编辑器发生渲染异常，可选择“保留草稿并以空白编辑器重试”，跳过原草稿和默认图；不要先清除浏览器站点数据，以免失去待恢复记录。

## 安装与离线使用

ScreenHello 独立站在 HTTPS（或本机 `localhost`）下完成首次加载后，会在 Service Worker 真正激活时显示“离线已就绪”。此后断网刷新仍可打开核心编辑器、导入本地图片并导出 PNG；看到页面曾经打开过，不代表缓存已经完成，应以该状态提示为准。

- Chrome/Edge 只有在浏览器发出可安装能力事件时才显示“安装”按钮；也可使用地址栏或浏览器菜单中的安装入口。提示被关闭后，本次页面不再反复打扰。
- iPhone/iPad 会提供手动步骤：打开 Safari 分享菜单，选择“添加到主屏幕”，并启用“作为 Web App 打开”。
- Firefox desktop 与 Safari 16.4 desktop 没有统一的站内安装按钮；这不影响作为普通网页使用和已缓存的离线能力。
- AVIF Worker/WASM 等重资源不进入首次核心缓存。该能力只有在联网时成功使用一次后，才具备离线复用条件；未缓存时会给出明确失败提示，核心 PNG 编辑链路仍可用。代码原生背景无需下载。浏览器仍可能因 30 天过期策略或存储压力清理缓存。
- 应用发现新版本时不会静默覆盖正在编辑的内容。存在未保存更改时需要二次确认，导出或批量任务运行中则暂不允许更新；也可以选择“稍后”。

项目、草稿和用户图片仍保存在文件、IndexedDB 或内存中，不会写入 HTTP Cache/Service Worker Cache，也不会上传。

## 文件菜单、项目状态与本地资料库

独立站桌面/平板顶部提供“文件 / 编辑 / 视图 / 帮助”菜单。项目名区域分别显示项目文件与自动草稿状态，点击可重命名；当前工作只保存在本机，不需要账号，也不会上传或同步到云端。

在手机或低高度触控横屏中，顶栏收敛为“菜单 / 项目状态 / 导出”。“菜单”中的文件、编辑、视图、帮助四个分区与桌面使用同一套命令和可用状态；右侧“导出”始终打开完整导出面板。面板可用 Escape 或关闭按钮退出，焦点会回到原入口。

- “保存项目”会优先使用浏览器的系统文件保存能力；不支持时下载 `.screenhello` 文件。“另存为”始终重新选择目标。
- 项目文件和自动草稿是两份独立的本地保存：界面会分别显示它们的从未保存、等待、保存中、已保存或失败状态，不把草稿保存说成项目文件“已同步”。
- `.screenhello` 是包含项目文档、原图、可选上传背景和导出设置的便携 ZIP 容器。打开损坏、过大、版本不支持或缺少资源的文件时，当前画布不会被替换。
- 最近项目最多保留 12 条本地副本，可在刷新或新会话中重新打开；它不能替代用户自己保存的项目文件备份。
- “文件 → 本地资料库”以“最近项目 / 恢复草稿 / 风格预设 / 存储”四个 Tabs 管理持久内容；资料库可恢复或删除草稿，并显示浏览器估算的存储用量和持久化状态。浏览器仍可能按自身策略清理站点数据。
- Chromium 系浏览器在 HTTPS/localhost 且允许时使用 File System Access；Firefox、Safari 或能力不可用时使用文件选择与下载回退。
- 新建/清空、打开、恢复其他草稿或载入 PWA 新版本会替换当前编辑内容。存在未保存的项目文件更改时，可选“保存项目并继续”、“不保存并继续”或“取消”；保存取消/失败、取消清空或目标文件无效都会保留当前内存项目。

## 风格预设与本地建议

“文件 → 本地资料库 → 风格预设”可以把当前完整画面配置和已确认的导出设置（含压缩模式、PNG 色数及质量）保存为风格预设。预设支持应用、复制、重命名、删除，以及 `.screenhello-preset` 文件导入/导出；上传的本地背景会随预设一起保存。预设不替换当前原图或标注。项目文件与最近项目同样保留压缩设置；遇到无法识别的设置会提示并回退标准导出，不损坏可读画面。旧版软件可能忽略新压缩偏好，自动草稿也不备份这些偏好。

添加图片后，应用会在最多 64px 的本地 Canvas 预览上分析图片边缘，分析不发送图片且不会自动修改画布。背景建议位于“背景”，内描边建议位于“边框与阴影 → 内描边”，横/竖图外框建议位于左侧“外框”；每张卡片都显示“本地建议”、预览和值，只有点击“应用”才修改项目，并可通过撤销恢复。分析失败时可在对应位置重试。

## 更换图片

图片导入后仍可随时更换：

- 编辑状态下，通过“文件 → 替换当前图片…”选择新文件；移动端从“菜单 → 文件”进入同一命令。
- 也可以把 JPEG、PNG、BMP、GIF 或 WebP 文件拖到整个编辑画布，释放后直接替换当前图片。
- 独立站只在“唯一选中且未锁定的图片”时允许替换；多选、锁定或处理任务中会禁用并说明原因。
- 替换只改目标图层的原图，保留它的位置、缩放、旋转、层序、编组以及其他图片/标注，并可撤销/重做。
- 尚未开始编辑时，可以点击欢迎页中央的图片图标或“选择图片”按钮选择文件；也可将本地图片拖到图标、按钮或整个欢迎工作区。拖入时会提示“释放以添加图片”，离开或释放后提示消失。

## 多图片与图层布局

右侧“图片图层”分组可一次选择一个或多个本地图片追加到当前画布。单项目最多 12 个图片图层，唯一图片总计最多 1.2 亿像素；超过限制时当前项目不会被破坏。

- 每行显示直接复用本地图片资源的缩略图、名称、尺寸、锁定/编组状态；摘要显示已选数量与总层数。单击图层选择，按 Shift、Ctrl 或 Cmd 点击可多选；编组后选择任一成员会选择整组。
- 支持复制、删除、锁定/解锁，以及置顶、上移、下移和置底。也可拖动图层到目标层的上方/下方，或在图层按钮上按 `Alt+↑`、`Alt+↓`、`Alt+Home`、`Alt+End`；拖放不是唯一操作路径。锁定选择不会被重排。
- 支持左/水平中/右、上/垂直中/下对齐，水平/垂直等间距，以及堆叠和扇形布局。
- 图片可直接在画布移动、等比缩放和旋转；单选移动结束时会吸附画布或其他图片的边缘/中心。
- 所有多图几何、层序、编组和锁定状态都进入撤销/重做、草稿与 `.screenhello` 项目文件；导出始终包含整个画布上的全部图片。

## 导入图片

初始页支持：

- 点击中央图片图标或“选择图片”按钮，或拖放 JPEG、PNG、BMP、GIF、WebP 文件。图标可用 Tab 聚焦、Enter/空格激活；多个文件拖入时沿用单图导入，选择第一张受支持的图片。取消选择不改变画布，无效图片会提示并允许重试。
- 从剪贴板粘贴第一张受支持的图片。
- 点击相机按钮并授权浏览器进行屏幕捕获。
- 点击青绿色的“试用示例”按钮，按需读取随应用打包的本地网页截图。按点击时页面宽度选择：小于 768px 使用手机版示例，768px 及以上（平板/PC）使用横版示例；导入后调整窗口不会替换当前图片。未点击时不加载示例原图，也不加入 PWA 首次预缓存；使用过的版本可由同源运行时缓存离线复用，未缓存时会提示改选本地图片。加载有忙碌状态，失败后可以重试。
- 首屏直接显示“图片仅在此设备处理，不会上传”；点击“三步入门”可打开快速入门，关闭后仍可从“帮助 → 快速入门”再次打开。

当前界面不提供文本美化、代码美化和 GIF 入口；相关能力尚未实现。

## 画布尺寸

默认使用 `Auto`：导入或裁剪后保持 ScreenHello 的 4:3 默认画布策略。也可以输入自定义宽高，或选择以下预设：

- 常见比例：16:9、3:2、4:3、5:4、1:1、4:5、3:4、2:3、9:16。
- Instagram：Post、Portrait、Story（代码中标题目前拼写为 `Stroy`）。
- X：Tweet、Cover。
- YouTube：Banner、Thumbnail、Video。
- Pinterest：Long、Optimal、Square。

## 图片与背景设置

右侧栏可调整：

- 裁剪、水平翻转、垂直翻转。
- 图片在画布中的九宫格位置。
- 整体缩放（0.1–3）；使用浏览器外框时，网页内容和外框宽度随之缩放，浏览器顶部栏高度仍由左侧“顶部尺寸”独立控制。
- 内边距（滑杆 0–200，手动输入最高 500）和内边距颜色。
- 圆角（滑杆 0–100，手动输入最高 999）。
- 可独立启用的内描边（1–12）及颜色。
- 可独立启用的阴影及颜色，并可设置 X/Y 偏移、模糊和扩展。
- 常用背景、更多代码原生纯色/渐变、自定义纯色、25 张内置图片背景，以及上传本地背景。“图片背景 → 全部图片（25）”可查看完整图库，加载失败时保留当前背景。

内置背景不访问 Unsplash 或外部图片素材服务。纯色/渐变由浏览器直接绘制，新图片背景按需读取同源打包资源；所选图片随项目、预设和草稿保存，恢复不依赖外部 URL。完整图片不会全部预缓存，首次离线未必能选择尚未使用的背景，详见[图片背景](./preset-backgrounds.md)。`defaultImg` 若由宿主传入远程 URL，仍需远端允许 CORS 才能稳定导出。

## 外框

初始页左侧直接展示浏览器和设备两组快捷选项，下方“更多外框”打开全部样式。安装本地设备包后，默认展示 MacBook Air M2、iMac 24″、Surface Pro、Pixel 9 Pro；可以先选设备/配色再导入图片，选择会保留。其他可用型号从“更多外框”选择后也会显示在快捷区。无素材包时不显示设备快捷区；手机端从“菜单 → 视图 → 显示尺寸与外框”进入。

可选外框包括：

- 基础外框：无外框、浅色/深色描边、白色卡片、浅色/深色玻璃。
- 创意外框：单层/双层堆叠、拍立得。
- 浏览器外框：简洁浏览器、简洁浏览器深色、标签浏览器、标签浏览器深色和极简浏览器。
- 设备区固定提供 18 款 MIT 许可的 Devices.css 机型（iPhone 14 Pro / 14 / X / 8、Pixel 6 Pro / Pixel / Pixel 2 XL、Galaxy S8、iPad Pro 两代、MacBook Pro (2018) / MacBook Pro / MacBook、iMac、Pro Display XDR、Surface Book、Apple Watch Ultra / Series 8），共 35 个配色；这些素材随应用分发、离线可用，下载前不弹素材许可说明（侧栏仍给出作者与许可链接），型号名沿用上游写法。
- 安装可选本地素材包后，设备区提供 Surface Pro / Studio、MacBook Pro、MacBook Air M2、iMac 24″、iPad、iPhone、Pixel 9 Pro。Air M2 可选银/星光/深空灰/午夜色，iMac 可选五色；每型号一张卡片，选中后在“机身配色”切换，支持方向键与撤销。Pixel 是精细 SVG 转为透明 PNG 的机身，不是摄影素材。
- 自绘矢量框（通用笔记本/显示器/平板/手机）只服务旧项目，不再用于新建或推荐；旧项目仍按保存的 ID 恢复原框。已有历史 Air/iMac 项目也不会自动替换成新外形。

图片导出不附加底部文字。Surface 和其他第三方位图在下载前显示素材来源，已知时提供完整许可链接；界面不再重复显示“授权尚待核实”段落。Pixel 的 MIT 声明集中收录在第三方说明，不重复弹窗。素材包不随公开代码分发；已保存项目只含设备 ID，缺素材时必须安装对应素材或更换外框，不能导出缺失机身的画面。详见 [设备框说明](./raster-device-frames.md)。

选择浏览器外框后，左侧外框面板会直接显示浏览器设置，可输入展示在地址栏中的 URL，并把顶部尺寸调整为 50%–200%（默认 100%）。100% 已按清晰可读的浏览器工具栏尺寸设计；拖动主图四角或右侧缩放不会改变顶部栏高度。URL 仅用于画面展示，不会打开或抓取网站。设备框提供覆盖、包含、拉伸三种适配选项；项目文件中的历史拼写会自动迁移为当前的拉伸值。普通图片和浏览器标题栏固定使用 Cover。

## 标注工具

底部工具栏提供空心矩形、实心矩形、圆形、直线、箭头、画笔、放大镜、步骤编号和 Emoji。颜色与线宽会作为新标注默认值；若已有标注被选中，修改颜色或线宽也会作用于选中项。

手机或中心编辑区较窄时，完整工具栏会替换为左下角 44 px 标注入口。Sheet 首层显示常用形状和线条，“更多标注工具”包含放大镜、步骤、文字、模糊、马赛克、聚光和 Emoji，下方保留颜色、线宽与移动模式；选择工具后自动回到画布。

- 拖动创建大部分图形。
- 步骤编号单击创建，数字取当前最大编号加一。
- Emoji 从选择器插入到画布中心。
- 画笔保持启用，可连续绘制；其他工具完成一次绘制后自动退出。
- 手形按钮切换画布拖动模式。
- `Backspace` / `Delete` 删除选中标注。

“编辑”菜单提供项目级撤销/重做；标注、背景和受支持的样式操作会进入当前实例的历史记录。

## 水印与 HDR

文字水印支持内容、颜色、±45° 方向。默认覆盖整张成品；启用 “Only Background” 后，水印位于截图下方，只在背景区域显现。

HDR 是浏览器 Canvas 滤镜组合：提高饱和度、对比度和亮度并叠加 screen 效果。它不是高动态范围文件格式转换，处理大图时会增加内存和计算开销。

## 缩放与导出

桌面/平板画布控件可放大、缩小、选择 50%/100%/150%/200%，或适应可用空间。移动端右下角显示当前百分比，点击后提供放大、缩小、100% 和适应画布。这些操作只影响编辑视图，不改变最终画布尺寸。

导出设置支持：

- 格式：PNG、JPG、WebP、AVIF。AVIF 在本机按需编码，首次导出会加载本地 Worker/WASM，可能比其他格式慢。
- 像素倍率：1x、2x、3x。
- 下载或复制到剪贴板（复制固定为 PNG）。

右上角“导出”或“文件 → 导出图片…”会打开完整面板。格式、倍率和压缩模式先作为临时选择；成功交给系统保存后才记住设置，关闭、取消或失败不改变快速导出设置。文件菜单中的“使用当前设置快速导出”复用最近一次成功交付的设置。生成期间可取消；一旦开始系统保存便不可撤回写入，界面会等待系统操作结束，不伪造百分比。浏览器下载交付不保证用户最终落盘。

- PNG：标准导出、无损优化、有损减色（最多 256/128/64 色）。减色可能改变渐变和半透明阴影；无损优化不保证文件更小。
- JPG/WebP：有损支持高清/均衡/更小及 1～100 质量。质量 100 仍非无损，不同格式的数值不可直接比较。WebP 另支持真无损，但与其标准导出一样将透明区域填白。AVIF仅提供标准导出，不提供质量调节或压缩预览；旧压缩设置转为同格式/倍率标准设置，标准并不意味着无损。
- 可直接下载，也可点击“生成预览”查看真实大小。对比是同一编辑画面、同尺寸的标准导出，不是导入原图；PNG 显示实际节省或增大，不隐瞒负收益。
- 标准参照/结果切换、100% 滚动查看和浅/深底不会重新编码，预览底色不写入文件。下载有效预览使用同一个 Blob。设置或画面变化后预览失效，需手动重新生成，或明确选择直接导出；切换格式会重置草案为标准模式。
- PNG/JPG/WebP压缩下载最多4,194,304像素（约419万，例如2048×2048），完整预览最多1,048,576像素，单边最多8192。无法完整预览时仍可在下载限制内直接导出。AVIF只保留标准导出，最多4,194,304像素，不自动缩图或改格式。首次使用仍需加载同源编码资源，网络很慢时可能超时。当前调整尚未部署，验证见 [大图压缩下载](./compression-download.md)。

标准 PNG/JPG/WebP 最多导出 16,777,216 像素，标准 AVIF 因本地编码内存与耗时另限制为 4,194,304 像素；超限时请降低倍率或画布尺寸。AVIF 编码失败时界面会建议改用 PNG 或 WebP，不会上传图片到服务器转换。复制始终为标准 PNG，不使用压缩设置。设置确认会影响项目配置的未保存状态，但不会改画面或编辑历史；自动草稿不保存压缩偏好。

## 批量压缩与失败重试

“文件 → 批量处理”支持 1～12 张本地图片，使用当前已确认设置或本地预设。开始后固定风格、压缩参数与背景资源；面板显示本批次设置、每个成功文件的实际大小、图片输出合计和 ZIP 大小，不显示没有依据的整批压缩率。压缩下载逐张使用与单图一致的格式限制：Web 候选 PNG/JPG/WebP 约 419 万、AVIF 约 105 万像素，标准导出上限不变。超限项保留明确原因；旧项目/预设不自动改写，重试仍遵守相同限制。ZIP 交给系统保存期间会阻止重复保存、清空或重启批次；取消系统对话框或保存失败后可重试，原 ZIP 保留。

“重试失败项”只处理失败/取消项，沿用原批次风格，即使原预设已改动/删除、当前画面已变化也不改变重试结果。重试会用新 ZIP 替换面板中的旧 ZIP，且只含这次成功项；请先下载需要保留的旧 ZIP。要使用新设置，点击“开始批量处理”重新开始，或重新选择文件。背景/预设在初始读取阶段失败时不会建立可重试快照，需修复来源后重新开始。批量操作不反向改写单图压缩偏好，已下载到设备的文件不受清空操作影响。

## 渐变角度与样式重置

- 渐变色卡下方提供 0–360° 角度滑杆，拖动时实时预览，松开后随草稿、撤销/重做和导出保存。
- 左上角撤销/重做按钮右侧的“重置图片样式”会恢复缩放、翻转、内边距、圆角和阴影默认值，背景与浏览器外框配置保持不变。

## 隐私与“已上传 0 B”

顶栏常驻一个隐私徽标，显示本次会话**可精确测量的外部发送字节数**（默认 `已上传 0 B`）。
如果有请求体无法在不消费它的情况下精确测量，数字会显示为 `≥` 下界，并说明受影响的请求数。

- 数字来自运行时的网络出口监控：`fetch`、`XMLHttpRequest`、`navigator.sendBeacon`、`WebSocket`
  四个会发送数据的通道都会被统计；WebSocket 同时统计连接和成功的 `send()`。字符串、Blob、
  ArrayBuffer 与 URLSearchParams 按实际字节数计算；流式请求体和 multipart FormData 无法在不消费或
  序列化它们的情况下得知准确长度，会被单独标记为“无法确定”，而不是按 0 处理。
- 浮层里同时给出「外部请求 N 次」与「外部资源加载 N 个」（图片/脚本/样式等**只接收**的资源，
  来自 Resource Timing，浏览器不支持时该项不显示），以及最近一次外部请求的地址。
- “本机”指同源、`localhost`/`127.0.0.1`/`::1` 回环、`blob:`、`data:`、`file:`、`about:` 与相对地址。
  计数是**页面级**的：同一页面挂载多个编辑器时，它们显示同一个真实数字。
- 一旦有数据发往外部源，数字与徽标立刻变化（徽标转为告警色）；这条计数也在
  「帮助 → 本地数据与隐私」中实时显示。它是运行结论而不是宣传语——把任意一个请求发到外部地址
  就会看到它涨。
## 危险操作与撤销提示

删除图层、重置图片样式和移除背景（选择“无背景”）属于高频且容易恢复的操作：**直接执行，不弹二次确认**，执行后顶部会出现一条提示，右侧带“撤销”按钮。

- 点击“撤销”（默认 8 秒内有效）即可回到操作前，等价于撤销这一步；删除图层会连图层顺序一起恢复。
- 撤销提示只撤销它自己那一步。如果之后又做了新的编辑，旧提示不会生效——不会出现“撤销了后面的操作”这种情况，并会说明当前没有可撤销的操作。
- 提示只服务当前会话，刷新页面后不再保留；历史栈本身仍按撤销/重做规则保留 50 步。
- 嵌入式 `ImageBeautifier` 走同一套内部消息实例，行为一致；只有绕过组件直接调用 Store（`editor.setMessage` 未注入）时才不显示提示，操作本身不受影响。

本地资料库中低频、代价高的删除**仍先二次确认**，确认后同样会出现带“撤销”的提示：

- 删除草稿（“永久删除这个草稿？”）、删除预设和移除最近项目记录都会提示“已删除…/已移除记录…”，一次点击即可写回本地记录；草稿会连同它的图片资源一起恢复，预设会连同背景图片一起恢复。
- 撤销快照只在提示打开期间（默认 8 秒）保留：提示关闭后快照即可回收，持久化删除不做跨会话保留。
- “清空当前项目”（文件 → 新建项目，或顶栏的清空按钮）目前没有撤销：它会销毁画布并释放当前图片资源。项目有未保存改动时仍会先走保存/放弃确认，没有未保存改动时可直接清空，请先保存需要保留的项目文件或依赖自动草稿。
