# 内置图片背景

## 当前能力

“背景 → 图片背景”展示六张精选图；“全部图片（25）”打开完整图库。包含三张自然风景与 22 张抽象纹理，保留原有纯色、代码渐变和本地上传。标题、状态与错误提示支持七种界面语言。

图片背景支持已有的覆盖/包含/拉伸、位置、模糊、遮罩、噪点、撤销/重做及导出流程。加载成功前保留当前画面；失败时提示重试，快速切换、取消、清空和销毁会取消旧选择。单次加载等待上限 15 秒。

## 资源与兼容

- 25 张正式 WebP 合计 2,377,374 bytes，原尺寸编码（quality 94）；25 张 240×160 缩略图合计 55,138 bytes（quality 84）。缩略图中心裁切，大图不裁切、不放大；这不是无损编码，也不宣称 4K 分辨率。
- [资源清单](../src/assets/backgrounds/manifest.json) 记录来源类别、原件摘要、输出尺寸/字节/SHA-256；[素材来源](../ASSET_PROVENANCE.md) 区分项目生成与维护者提供。没有新增在线图库或第三方下载依赖。
- `image_n01_v1`～`image_n03_v1` 与 `image_u01_v1`～`image_u22_v1` 是新稳定标识。旧 `gh_img_*` 继续解析为原来的代码渐变，默认背景和组件 Props 不变。
- 完整图片只在用户选择时读取，再解码为当前实例拥有的 Blob。URL 不写入项目；项目/预设/草稿嵌入所选背景字节，不需要恢复时联网。缺少图片字节的项目/预设会拒绝恢复。
- 撤销历史同时保留背景 Blob，随着最多 50 步历史回收；只清理已提交且不再被引用的背景，不干扰尚在导入的资源或其他实例。
- Web 与 library 保持完整图/缩略图独立文件；现有库资源重写插件会把 `no-inline` 透传给宿主。移动端内外层 Drawer 均关闭推移，Portal 内保留选中描边及主题色回退。
- PWA 核心缓存包含缩略图，不含任何完整背景；大图使用现有按需缓存。首次离线未必能选择全部图片，已保存草稿/项目中的背景仍可本地恢复。浏览器可能清理缓存。

## 回归入口

- `tests/unit/presetBackgrounds.test.js`：资源完整性/预算、旧 token、安全序列化、实例隔离、历史资源、失败/竞争/超时/取消及存档。
- `tests/e2e/preset-backgrounds.spec.js`：三引擎逐张解码、图库交互、失败重试、项目/预设和导出像素。
- consumer：真实组件库打包、两个实例独立选择/卸载和下载。
- PWA：核心/按需缓存边界、断网冷恢复、未缓存背景失败后仍可导出。

这些是 Web 实现与本地验证范围，不代替最低浏览器或真实 Safari/原生桌面验收；本次未发布。
