## 기기에서 처리하는 작업

가져온 이미지, 캡처, 캔버스 편집과 압축은 내 기기 브라우저에서 처리됩니다. 이미지 업로드 백엔드, 클라우드 계정이나 동기화는 없습니다. 로컬 우선이라는 말이 웹사이트 로딩 시 네트워크 요청도 없다는 뜻은 아닙니다.


## 저장과 네트워크 요청

프로젝트, 초안과 프리셋은 IndexedDB에, 언어와 테마 설정은 로컬에 저장될 수 있습니다. 코드, 아이콘, 배경과 인코더는 필요할 때 사이트에서 요청합니다. 호스팅 업체는 IP와 브라우저 식별 정보 같은 일반 접속 메타데이터를 처리할 수 있습니다. 이 소스 버전에는 분석 SDK, 광고 픽셀이나 세션 녹화를 추가하지 않습니다.


## 삭제하거나 다른 기기로 옮기기

로컬 라이브러리에서 초안, 프리셋과 최근 프로젝트를 관리하거나 브라우저 설정에서 사이트 데이터를 지우세요. 먼저 보관할 .screenhello 파일을 저장해야 합니다. 브라우저 데이터 삭제는 이미 다운로드한 파일을 지우지 않습니다. 외부 소스 코드 링크에는 이동한 사이트의 정책이 적용됩니다.
