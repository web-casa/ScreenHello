## 기기에서 처리하는 작업

가져온 이미지, 캡처, 코드·텍스트 카드 렌더링, 3D 원근 변환, 사용자 지정 로고 워터마크(&lt;= 64 KiB)와 소셜 카드 아바타(&lt;= 32 KiB) 압축, 그리고 이미지 압축과 GIF89a/WebM 인코딩은 모두 내 기기 브라우저나 로컬 Web Worker에서 실행됩니다. 업로드 백엔드, 클라우드 계정이나 동기화는 없습니다.


## 저장과 네트워크 요청

프로젝트, 초안과 프리셋은 IndexedDB에 저장될 수 있으며 사용자가 추가한 로컬 아바타·로고 이미지 데이터도 기기에만 남습니다. 언어와 테마 설정도 로컬에 저장됩니다. 코드, 아이콘, 배경과 인코더는 필요할 때 사이트에서 요청하며 이 소스 버전에는 분석 SDK, 광고 픽셀이나 세션 녹화가 없습니다.


## 삭제하거나 다른 기기로 옮기기

로컬 라이브러리에서 초안, 프리셋과 최근 프로젝트를 관리하거나 브라우저 설정에서 사이트 데이터를 지우세요. 먼저 보관할 .screenhello 파일을 저장해야 합니다. 브라우저 데이터 삭제는 이미 다운로드한 파일을 지우지 않습니다. 외부 소스 코드 링크에는 이동한 사이트의 정책이 적용됩니다.
