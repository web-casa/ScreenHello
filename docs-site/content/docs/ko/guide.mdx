## 1. 예제 열기, 이미지 가져오기 또는 카드 만들기

이 페이지의 편집기 열기를 누른 다음 중앙의 예제 버튼이나 시작 화면의 코드 카드·텍스트 카드·장면 템플릿 빠른 버튼을 선택하세요. 자신의 스크린샷을 쓰려면 이미지 선택으로 로컬 파일을 가져오세요.


## 2. 배경, 프레임, 3D 원근과 워터마크 설정

오른쪽에서 배경, 여백, 모서리, 그림자와 텍스트·이미지 로고 워터마크를 설정하고 레이어 목록의 눈 버튼으로 표시를 전환하세요. 왼쪽에서 캔버스 크기, 브라우저 프레임, 3D 원근 프리셋 또는 18개 장면 템플릿을 고릅니다.

## 3. 크기 확인 후 이미지 또는 애니메이션 다운로드

상단 내보내기에서 PNG, 표준 내보내기와 1× 배율을 확인한 뒤 이미지를 다운로드하세요. 반복 모션이 필요하면 파일 → 애니메이션 내보내기에서 미리 보고 로컬로 GIF89a 또는 WebM을 저장합니다.


<GuideImage src="/guide/en-US-export.png" caption="내보내기 패널에서 형식과 배율을 선택하고 최종 크기를 확인한 후 다운로드하세요. 영어 화면을 사용한 예시입니다." />

## 4. 편집 가능한 프로젝트 저장

파일 메뉴에서 .screenhello 프로젝트 파일을 저장하세요. 다운로드한 이미지나 GIF는 완성본이며 프로젝트 파일은 레이어 표시 상태, 코드·텍스트 카드, 3D 원근과 로고 워터마크를 그대로 보존합니다.


## 초안과 별도로 백업하세요

파일 메뉴의 프로젝트 저장 또는 다른 이름으로 저장으로 백업하고 프로젝트 열기로 복원하세요. 초안과 최근 프로젝트는 클라우드가 아닌 현재 브라우저에 있습니다. 사이트 데이터를 지우기 전에 파일을 저장하고 다른 기기로는 직접 옮기세요. 자동 동기화는 없습니다.


## 오프라인과 문제 해결

오프라인 준비 완료 후 캐시된 편집기 핵심은 인터넷 없이 다시 열 수 있습니다. 사용하지 않은 배경, 기기와 인코더는 최초 온라인 로딩이 필요할 수 있습니다. 이 가이드는 편집기 오프라인 캐시에 포함되지 않아 네트워크가 필요합니다. 권한이 거부되면 로컬 파일을 사용하고 내보내기 한도를 넘으면 크기나 배율을 줄이세요.
