## 1. 이미지 가져오기 또는 카드 만들기

파일을 선택하거나 시작 화면에 끌어 놓고 클립보드 이미지를 붙여 넣을 수 있습니다. 시작 화면의 빠른 버튼으로 코드 카드(14개 언어 오프라인 구문 강조, 6개 테마, 줄 범위 및 +/- Diff 강조), 텍스트·소셜 카드(소셜 게시물, 인용문, 변경 로그)를 만들거나 18개 장면 템플릿을 바로 열 수도 있습니다.

### 최대 12개 레이어와 표시 전환

프로젝트 하나에 최대 12개의 이미지·카드 레이어를 담습니다. 각 레이어는 위치·크기·스타일을 유지하며 레이어 목록의 눈 버튼으로 삭제 없이 숨기거나 표시할 수 있습니다. 숨긴 레이어는 내보내기에서 제외되며 실행 취소를 지원합니다.

### 키보드 단축키

키보드에서 손을 떼지 않고 편집기를 다룹니다. macOS에서는 Ctrl 대신 Command를 씁니다.

| 동작 | 키 |
| --- | --- |
| 프로젝트 열기 | Ctrl + O |
| 프로젝트 저장 | Ctrl + S |
| 다른 이름으로 저장 | Ctrl + Shift + S |
| 내보내기 열기 | Ctrl + Shift + E |
| 완성 이미지 복사 | Ctrl + C |
| 실행 취소 | Ctrl + Z |
| 다시 실행 | Ctrl + Shift + Z |
| 선택 삭제 | Delete / Backspace |
| 확대 | Ctrl + + |
| 축소 | Ctrl + - |
| 화면에 맞추기 | Ctrl + 0 |

> 텍스트 필드에 입력하는 동안에는 단축키가 동작하지 않아 입력을 방해하지 않습니다.

## 2. 스타일, 장면 템플릿과 워터마크 설정

캔버스 크기(1.618:1 황금비, OG 1200×630, Product Hunt, Xiaohongshu, LinkedIn 포함), 안쪽 여백, 모서리, 그림자와 안쪽 테두리를 조정하세요. 단색·그라데이션·내장 배경·내 이미지를 쓰거나 18개 장면 템플릿을 한 번에 적용(단일 실행 취소 지원)할 수 있습니다. 텍스트 또는 로컬 압축 &lt;= 64 KiB 이미지 로고 워터마크(9분할·바둑판)와 화살표·단계 번호·돋보기를 추가하세요.


## 3. 정적 이미지 또는 반복 애니메이션 내보내기

투명 배경이 필요하면 PNG를 선택하고 JPG, WebP, AVIF도 내보낼 수 있습니다(JPG·WebP는 투명 부분을 흰색으로 채움). 제품 소개용 모션이 필요하면 파일 → 애니메이션 내보내기에서 5가지 반복 마이크로 애니메이션을 미리 보고 로컬로 GIF89a 또는 WebM을 생성하세요.
