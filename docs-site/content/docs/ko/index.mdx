## 스크린샷을 완성된 소개 이미지로

로컬 이미지를 열거나 클립보드에서 붙여 넣고, 내장 예시도 사용해 보세요. 여백, 배경, 프레임과 주석으로 제품 소식, 사용 설명, 소셜 게시물을 만들 수 있습니다. 이미지는 내 기기에서 처리되며 계정이나 클라우드 동기화가 필요 없습니다.


## 편집한 프로젝트를 보관하세요

최대 12개의 이미지 레이어를 배치하고 변경 사항을 실행 취소할 수 있습니다. .screenhello 프로젝트 파일로 저장하면 다시 편집할 수 있습니다. 프로젝트 파일은 직접 보관하는 백업이며, 브라우저 자동 초안은 사이트 데이터 삭제 시 사라질 수 있는 별도 사본입니다.


## 현재 제공되는 기능

PNG, JPG, WebP, AVIF로 내보내고 다운로드 전에 압축 미리보기를 비교하세요. 여기서는 웹 편집기를 설명합니다. 데스크톱 빌드는 아직 테스트 후보이며 Chrome/Edge 확장 프로그램은 계획 단계로 정식 다운로드가 아닙니다. AVIF는 표준 내보내기만 제공하며 품질 조절이나 압축 미리보기는 제공하지 않습니다.
