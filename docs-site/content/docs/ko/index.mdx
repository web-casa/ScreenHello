## 스크린샷을 완성된 소개 이미지로

로컬 이미지를 열거나 클립보드에서 붙여 넣고 내장 예시를 사용해 보세요. 시작 화면에서 바로 코드 카드, 텍스트·소셜 카드를 만들거나 18개 장면 템플릿을 적용할 수도 있습니다. 여백, 배경, 3D 원근, 브라우저 프레임, 텍스트·이미지 로고 워터마크와 주석을 추가할 수 있으며 모든 처리는 내 기기에서 이루어집니다.


## 편집한 프로젝트를 보관하세요

최대 12개의 이미지·카드 레이어를 배치하고 눈 아이콘으로 레이어 표시를 전환하며 실행 취소/다시 실행을 지원합니다. .screenhello 프로젝트 파일에는 코드·텍스트 카드, 3D 원근과 로고 워터마크 설정이 함께 저장됩니다. 프로젝트 파일은 직접 보관하는 백업이며, 브라우저 자동 초안은 사이트 데이터 삭제 시 사라질 수 있습니다.


## 현재 제공되는 기능

PNG, JPG, WebP 정적 내보내기와 압축 미리보기, 표준 AVIF 내보내기는 물론 5가지 반복 마이크로 애니메이션의 로컬 GIF89a(및 브라우저 지원 WebM) 내보내기를 제공합니다. 여기서는 웹 편집기를 설명합니다. 데스크톱 빌드는 아직 테스트 후보이며 Chrome/Edge 확장 프로그램은 계획 단계입니다. AVIF는 표준 내보내기만 제공하며 품질 조절이나 압축 미리보기는 제공하지 않습니다.
