## 품질 100이 무손실은 아닙니다

PNG 무손실 최적화는 픽셀을 유지하지만 항상 파일이 작아지는 것은 아닙니다. 손실 모드는 256, 128, 64색으로 줄여 그라데이션이나 반투명 그림자를 바꿀 수 있습니다. WebP는 별도 무손실 모드를 제공합니다. JPG, WebP 품질 슬라이더는 100이어도 손실 방식이며 WebP는 인코딩 전에 투명 부분을 흰색으로 채웁니다. AVIF는 표준 내보내기만 제공하며 품질 조절이나 압축 미리보기는 제공하지 않습니다.

### 표준, 무손실, 손실

표준 내보내기는 각 형식의 기본 인코딩 설정을 사용합니다. PNG와 WebP는 무손실 모드를, JPG와 WebP는 품질을 조절하는 손실 모드를 제공합니다. AVIF는 품질 조절이나 압축 미리보기 없이 표준 내보내기만 제공합니다.

### 마주치는 한도

아래 값은 다운로드를 시작하기 전에 편집기가 확인합니다.

| 작업 | 한도 |
| --- | --- |
| 앱 내 전체 미리보기 | 1,048,576 픽셀(약 1 MP) |
| 압축 다운로드 | 4,194,304 픽셀(약 4 MP), 최장 변 8192 px |
| AVIF 내보내기 | 4,194,304 픽셀, 표준 내보내기만 |
| PNG 팔레트 축소 | 256, 128, 64색 |
| 손실 품질 프리셋 | JPG / WebP: 90 / 80 / 60 |
| 내보내기 배율 | 1x, 2x, 3x |
| 압축 제한 시간 | 30초 |

> AVIF는 표준 내보내기만 됩니다. 품질 조절과 압축 미리보기가 없습니다.

## 같은 캔버스를 비교합니다

내보내기에서 미리보기를 생성하고 같은 크기의 표준 결과와 압축 결과를 비교하세요. 100% 보기와 실제 바이트 크기로 확인할 수 있습니다. 기준은 가져온 원본이 아니라 편집된 전체 화면이며 파일이 커져도 그대로 표시합니다. 유효한 미리보기 다운로드는 생성된 동일 데이터를 사용합니다.


## 픽셀 제한과 로컬 처리

AVIF는 표준 내보내기만 제공하며 품질 조절이나 압축 미리보기는 제공하지 않습니다. PNG/JPG/WebP 압축 다운로드는 4,194,304픽셀까지 지원합니다. PNG/JPG/WebP 전체 미리보기는 1,048,576픽셀까지 지원합니다. 미리보기를 사용할 수 없어도 다운로드 제한 내에서 바로 내보낼 수 있습니다. 표준 PNG/JPG/WebP는 16,777,216픽셀, 표준 AVIF는 4,194,304픽셀, 각 변은 8192픽셀까지입니다. 초과하면 캔버스나 배율을 줄이세요. 인코더는 처음에 이 사이트에서 불러와 로컬로 실행하며 일괄 처리는 최대 12장의 성공 결과를 ZIP으로 제공합니다.
