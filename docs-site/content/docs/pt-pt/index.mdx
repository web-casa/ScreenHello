## Da captura à apresentação

Abra uma imagem local, cole a partir da área de transferência ou experimente o exemplo incluído. Adicione espaço, fundos, molduras e anotações para novidades de produto, tutoriais e publicações. As imagens são processadas no seu dispositivo, sem conta nem sincronização na nuvem.


## Guarde um projeto editável

Organize até 12 camadas de imagem, anule alterações e guarde um ficheiro portátil .screenhello. Este ficheiro é a sua cópia de segurança. Os rascunhos automáticos do navegador são cópias locais separadas e podem desaparecer ao limpar os dados do site.


## Funcionalidades Web e disponibilidade

Exporte PNG, JPG, WebP ou AVIF e compare uma pré-visualização da compressão. Estas páginas descrevem o editor Web. As versões para computador ainda são candidatas de teste; a extensão Chrome/Edge está planeada e não é uma versão final disponível para transferência. O AVIF só permite exportação padrão, sem controlo de qualidade nem pré-visualização de compressão.
