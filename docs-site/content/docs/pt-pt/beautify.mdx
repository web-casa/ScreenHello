## 1. Importar uma imagem ou criar um cartão

Escolha um ficheiro, arraste-o para a área inicial, cole uma imagem ou use os atalhos iniciais para criar um cartão de código (14 linguagens offline, 6 temas, destaque de linhas e modo +/- diff), um cartão de texto/social (publicação, citação ou registo de alterações) ou abrir a galeria de 18 modelos. A captura de ecrã requer autorização do navegador.

### Até 12 camadas com controlo de visibilidade

Um projeto comporta no máximo 12 camadas de imagem ou cartão. Cada uma mantém posição e aspeto e pode ser ocultada ou mostrada na lista sem a eliminar; camadas ocultas não entram na exportação e suportam anular/refazer.

### Atalhos de teclado

Controle o editor sem largar o teclado. No macOS use Command onde a tabela diz Ctrl.

| Ação | Teclas |
| --- | --- |
| Abrir projeto | Ctrl + O |
| Guardar projeto | Ctrl + S |
| Guardar como | Ctrl + Shift + S |
| Abrir exportação | Ctrl + Shift + E |
| Copiar imagem final | Ctrl + C |
| Anular | Ctrl + Z |
| Refazer | Ctrl + Shift + Z |
| Eliminar seleção | Delete / Backspace |
| Ampliar | Ctrl + + |
| Reduzir | Ctrl + - |
| Ajustar à tela | Ctrl + 0 |

> Os atalhos ficam inativos enquanto escreve num campo de texto.

## 2. Criar estilo, modelos e marca de água

Ajuste o tamanho da tela (incluindo 1.618:1, OG 1200×630, Product Hunt, Xiaohongshu e LinkedIn), margem interior, cantos, sombra e contorno interior. Escolha cores, gradientes, fundos próprios ou aplique qualquer um dos 18 modelos num só passo reversível. Adicione marcas de água de texto ou logótipo local comprimido (&lt;= 64 KiB, grelha 3×3 ou mosaico), setas, números de passo e lupas.


## 3. Exportar imagens fixas ou animações em ciclo

Escolha PNG para transparência ou exporte JPG, WebP e AVIF (JPG e WebP preenchem áreas transparentes a branco). Para animações em ciclo, abra Ficheiro → Exportar animação para pré-visualizar 5 microanimações e codificar GIF89a ou WebM localmente. O zoom só altera a vista; a escala altera os píxeis finais.
