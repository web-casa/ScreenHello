## What is processed locally?

Imported images, captured screenshots, canvas editing, code and text card rendering, 3D perspective transforms, custom logo watermarks (&lt;= 64 KiB) and social card avatars (&lt;= 32 KiB), plus image compression and GIF89a/WebM motion encoding all run in your device's browser or local Web Workers. This application has no upload backend, cloud account or cloud synchronisation. Local-first does not mean that loading the website makes no network requests.


## What is stored or requested?

Projects, drafts and presets can be stored in IndexedDB (including any local avatar or logo image data you add); language and appearance preferences are saved locally. The browser requests the site code, icons, backgrounds and encoding resources as needed. Hosting providers may process ordinary request metadata such as IP addresses and user agents. This source version adds no analytics SDK, advertising pixel or session recording.


## How can I remove or move my data?

Manage drafts, presets and recent projects in the local library, or clear this site's data in browser settings. First save any .screenhello project files you want to keep. Clearing browser data does not delete files already downloaded to your device. External source-code links leave this site and are governed by the destination's policies.
