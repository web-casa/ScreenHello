## A browser frame, without fetching a website

Choose a browser frame from the left panel, enter the address shown in the title bar and adjust the toolbar size. The displayed address is decoration: ScreenHello does not visit the URL or capture that website automatically.

### Browser chrome or device frame

Browser chrome draws a title bar around the canvas and needs no extra assets. Raster device frames reproduce a specific screen and keep the source aspect ratio.

> Raster device frames come from an optional local pack. When the pack is not installed the picker says so instead of showing an empty list, and every other feature keeps working.

## Devices depend on installed artwork

The frame picker shows only artwork available in the current build. Some local installations include MacBook Air M2, iMac 24-inch, Surface Pro, Surface Studio or Pixel 9 Pro variants. These are not guaranteed in the public distribution; available colour choices also depend on the installed pack.


## Preserve proportions and respect licences

Use contain to keep the entire screenshot, cover to fill the display with cropping, or stretch when distortion is acceptable. Optional artwork has its own licence; the application's code licence does not automatically cover it. A saved project stores a device identifier, not the optional device pack. Missing artwork must be installed or replaced before a complete export.
