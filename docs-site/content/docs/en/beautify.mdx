## 1. Bring in an image or create a card

Choose a local file, drop it into the welcome area, paste an image, or use the welcome quick-create shortcuts to build a code card (14 languages, 6 themes, line range highlights and +/- diff mode), a text/social card (social post, quote poster or changelog), or open the 18-template scene gallery. Screen capture asks for browser permission. The example button loads a portrait sample on narrow screens and a landscape sample on wider windows.

### Work with up to 12 layers and visibility toggles

A project holds at most 12 image or card layers. Each one keeps its own position, size and appearance settings, and you can hide or show any layer from the layer list without deleting it—hidden layers stay out of interaction and export and participate in undo/redo.

### Keyboard shortcuts

Drive the editor without leaving the keyboard. On macOS use Command wherever the table says Ctrl.

| Action | Keys |
| --- | --- |
| Open project | Ctrl + O |
| Save project | Ctrl + S |
| Save project as | Ctrl + Shift + S |
| Open export | Ctrl + Shift + E |
| Copy final image | Ctrl + C |
| Undo | Ctrl + Z |
| Redo | Ctrl + Shift + Z |
| Delete selection | Delete or Backspace |
| Zoom in | Ctrl + + |
| Zoom out | Ctrl + - |
| Fit canvas | Ctrl + 0 |

> Shortcuts are ignored while you are typing in a text field, so they never interrupt a label you are editing.

## 2. Build a consistent style and apply templates

Set canvas sizes (including 1.618:1 golden ratio, OG 1200×630, Product Hunt, Xiaohongshu and LinkedIn presets), padding, corner radius, shadow and inner border. Choose a solid colour, gradient, bundled backdrop or local background, or apply any of 18 built-in scene templates atomically in one undoable step. Add text or locally compressed image logo watermarks (&lt;= 64 KiB, 9-grid or tiled), arrows, step numbers and magnifiers, and save reusable styles as local presets.


## 3. Export static visuals or looped motion

Choose PNG for a transparent canvas, or JPG, WebP and AVIF for the other static workflows (JPEG and WebP flatten transparency to white). For launch teasers or social loops, open File → Export motion to preview 5 seamless micro-animations and encode GIF89a or WebM locally. Zoom changes only the editing view; export scale changes the final pixel dimensions.
