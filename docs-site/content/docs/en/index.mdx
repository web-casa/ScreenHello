## From a screenshot to a finished visual

Import a local image, paste from the clipboard, try the bundled example, or start from the welcome shortcuts with a code card, text/social card, or one of 18 built-in scene templates. Add padding, backgrounds, 3D perspective, browser frames, text or image logo watermarks and annotations for launches, tutorials and social posts. Everything runs on your device; no account or cloud sync is required.

### Cards, templates and backgrounds

Build syntax-highlighted code cards (14 languages, 6 themes, line highlights and +/- diff mode) or social, quote and changelog cards, or apply any of 18 scene templates in one undoable step. Combine with solid colours, gradients, bundled backdrops or your own local image.

### 3D perspective, frames, watermarks and annotations

Switch between 8 live-preview 3D perspective presets, browser chrome or optional raster device frames. Add text or locally compressed image logo watermarks (&lt;= 64 KiB), arrows, step numbers and magnifiers.

> Everything runs in your browser. There is no account, no upload and no cloud sync, so a screenshot never leaves your device.

## Edit once. Keep the project.

Arrange up to 12 image or card layers, toggle layer visibility without deleting, undo changes and save a portable .screenhello project (preserving code/text card metadata, 3D perspective and logo watermarks). A project file is your own backup; an automatically saved browser draft is a separate local copy and may be cleared by the browser.


## A Web tool with clear boundaries

Export PNG, JPG or WebP with local compression previews, standard AVIF, or render 5 seamless looped micro-animations to local GIF89a (and browser-supported WebM). The Web editor is the available workflow described here. Desktop builds are still test candidates, and a Chrome/Edge extension is planned, not offered as a released download. AVIF offers standard export only, without quality controls or compression preview.
