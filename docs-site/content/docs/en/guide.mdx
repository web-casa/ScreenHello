## 1. Open an example, import an image or create a card

Use Open editor on this page, then select Try an example in the centre of the canvas, or click the welcome quick-create shortcuts for a Code card, Text card or Scene templates. To use your own screenshot, choose Choose image and pick a local file. Continue once your content appears in the central canvas.


## 2. Set background, frame, 3D perspective and watermark

Use Background on the right to choose a solid colour, gradient or image, adjust padding, corners, shadow and text or image logo watermark, and toggle layer visibility in the layer list. Set canvas size, browser frame, 3D perspective presets or browse 18 scene templates on the left. Use bottom tools for annotations when needed.


<GuideImage src="/guide/en-US-editor.png" caption="The editor with the built-in example. Canvas settings are on the left; appearance controls are on the right." />

## 3. Check dimensions and download an image or loop

Select Export at the top, choose PNG, standard export and 1× scale, check the final pixel dimensions and select Download image. For looped motion, open File → Export motion to preview an animation and encode GIF89a or WebM locally. Canvas zoom does not change output dimensions; 2× scale doubles both width and height.


<GuideImage src="/guide/en-US-export.png" caption="The export panel: choose a format and scale, check the final size, then download." />

## 4. Save an editable project

Choose Save project in the File menu to save a .screenhello file. Downloaded images and GIFs are finished outputs; the project file preserves editable layers, visibility states, code/text card settings, 3D perspective and logo watermarks. Later, use File → Open project to resume editing.


## Save a file, not just a draft

Use File → Save project or Save as for a portable backup. File → Open project restores it. Local drafts and recent projects live in this browser, not in a cloud account. Clearing site data can remove them. Save a project file before clearing storage or moving to another device; transfer that file yourself.


## Offline and troubleshooting

After the editor reports offline readiness, its cached core can reopen without a connection. Unused backgrounds, optional devices and encoders may still require a first online load. These guide pages require a connection and are not part of the offline editor cache. If capture or clipboard access is denied, use a local file instead. If export exceeds its budget, lower the canvas dimensions or pixel scale.
