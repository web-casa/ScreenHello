## 1. Bild öffnen oder Karte erstellen

Wähle eine Datei, ziehe sie in den Begrüßungsbereich, füge ein Bild ein oder nutze die Schnellaktionen für Code-Karten (14 Sprachen mit Offline-Syntaxhervorhebung, 6 Designs, Zeilen- und +/- Diff-Markierung), Text-/Social-Karten (Beitrag, Zitat, Changelog) oder die 18 Szenenvorlagen. Die Bildschirmaufnahme benötigt eine Browserfreigabe; das Beispiel lädt je nach Fensterbreite im Hoch- oder Querformat.

### Bis zu 12 Ebenen mit Sichtbarkeitsschalter

Ein Projekt fasst höchstens 12 Bild- oder Kartenebenen. Jede behält Position, Größe und Darstellung und lässt sich über das Augen-Symbol vorübergehend aus- und einblenden; ausgeblendete Ebenen werden nicht exportiert und unterstützen Rückgängig/Wiederholen.

### Tastenkürzel

Bedienen Sie den Editor ohne die Tastatur zu verlassen. Unter macOS gilt Command statt Ctrl.

| Aktion | Tasten |
| --- | --- |
| Projekt öffnen | Ctrl + O |
| Projekt speichern | Ctrl + S |
| Projekt speichern unter | Ctrl + Shift + S |
| Export öffnen | Ctrl + Shift + E |
| Fertiges Bild kopieren | Ctrl + C |
| Rückgängig | Ctrl + Z |
| Wiederholen | Ctrl + Shift + Z |
| Auswahl löschen | Delete / Backspace |
| Vergrößern | Ctrl + + |
| Verkleinern | Ctrl + - |
| An Canvas anpassen | Ctrl + 0 |

> In einem Textfeld sind Tastenkürzel inaktiv und unterbrechen die Eingabe nicht.

## 2. Stil, Vorlagen und Wasserzeichen kombinieren

Stelle Leinwandgröße (inklusive 1.618:1, OG 1200×630, Product Hunt, Xiaohongshu und LinkedIn), Innenabstand, Rundungen, Schatten und Innenrahmen ein. Wähle Farben, Verläufe, mitgelieferte oder eigene Hintergründe oder wende eine von 18 Szenenvorlagen in einem rückgängig machbaren Schritt an. Ergänze Text- oder lokal komprimierte Bild-Logo-Wasserzeichen (&lt;= 64 KiB, 9er-Raster oder gekachelt) sowie Pfeile, Schrittnummern und Lupen.


## 3. Standbilder oder Schleifen-Animationen exportieren

Verwende PNG für Transparenz oder exportiere JPG, WebP und AVIF (JPG und WebP füllen transparente Bereiche weiß). Für Produkt-Teaser wähle Datei → Animation exportieren, um 5 nahtlose Mikroanimationen lokal als GIF89a oder WebM zu kodieren. Der Ansichtszoom ändert nicht die Ausgabegröße; dafür ist der Exportmaßstab zuständig.
