## 什么在本机处理？

导入图片、屏幕截图、画布编辑与压缩均在你的设备浏览器中完成。本应用没有图片上传后端、云账号或云同步。本地优先不等于打开网站时完全不产生网络请求。


## 会保存或请求什么？

项目、草稿和预设可保存在 IndexedDB，语言与外观偏好也保存在本地。浏览器按需请求本站代码、图标、背景和编码资源。托管服务可能处理 IP 地址、浏览器标识等普通访问元数据；本源码版本不加入分析 SDK、广告像素或会话录制。


## 如何删除或迁移数据？

可以在本地资料库管理草稿、预设和最近项目，或在浏览器设置中清理本站数据。请先保存想保留的 .screenhello 文件。清理浏览器不会删除已下载到设备的文件。点击外部源代码链接会离开本站，并适用目标站点的规则。
