## 从截图，到一张完整的展示图

选择本地图片、粘贴剪贴板图片、试用内置示例，或直接在首屏新建代码卡片、文本/社交卡片并套用 18 套场景模板。添加留白、背景、3D 透视、浏览器外框、自定义文字或图片 Logo 水印与标注，用于产品更新、操作教程和社交分享。全部渲染在你的设备上完成，不需要账号，也没有云同步。


## 编辑完成，项目也能带走

一个画布可编排最多 12 个图层，支持图层眼睛显隐切换、完整撤销/重做，并保存可继续编辑的 .screenhello 项目文件（含代码卡片、文本卡片、3D 透视与自定义水印配置）。项目文件是你主动保存的备份；浏览器自动草稿是另一份本地副本，可能随站点数据清理而丢失。


## Web 能力与发布状态说清楚

支持 PNG、JPG、WebP 静态导出及压缩预览，支持标准 AVIF 导出，并支持 5 种无缝循环微动画的本地 GIF89a（以及浏览器原生支持的 WebM）动图导出。这里介绍的是 Web 编辑器工作流；桌面版仍是测试候选，Chrome/Edge 扩展属于规划，不提供已正式发布的下载承诺。AVIF 仅提供标准导出，不提供质量调节或压缩预览。
