## 从截图，到一张完整的展示图

选择本地图片、粘贴剪贴板图片，或试用内置示例。添加留白、背景、浏览器外框与标注，用于产品更新、操作教程和社交分享。图片在你的设备上处理，不需要账号，也没有云同步。


## 编辑完成，项目也能带走

一个画布可编排最多 12 张图片，支持撤销操作，并保存可继续编辑的 .screenhello 项目文件。项目文件是你主动保存的备份；浏览器自动草稿是另一份本地副本，可能随站点数据清理而丢失。


## Web 能力与发布状态说清楚

支持 PNG、JPG、WebP 和 AVIF 导出，可在下载前比较压缩预览。这里介绍的是 Web 编辑器工作流；桌面版仍是测试候选，Chrome/Edge 扩展属于规划，不提供已正式发布的下载承诺。 AVIF 仅提供标准导出，不提供质量调节或压缩预览。
