## 第一步：放入图片

点击选择图片、拖入欢迎区，或粘贴剪贴板图片。截取屏幕需要浏览器授权。试用示例会在窄屏加载手机截图，在平板和桌面宽度加载横版截图，原图只在点击后读取。

### 最多 12 张图片

一个项目最多容纳 12 张图片。每张各自保留位置、尺寸与外观设置。

### 快捷键

不离开键盘就能操作编辑器。表中 Ctrl 在 macOS 上对应 Command。

| 操作 | 快捷键 |
| --- | --- |
| 打开项目 | Ctrl + O |
| 保存项目 | Ctrl + S |
| 另存项目 | Ctrl + Shift + S |
| 打开导出 | Ctrl + Shift + E |
| 复制成品图 | Ctrl + C |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z |
| 删除所选 | Delete / Backspace |
| 放大 | Ctrl + + |
| 缩小 | Ctrl + - |
| 适应画面 | Ctrl + 0 |

> 在文本框中输入时快捷键不生效，不会打断你正在编辑的文字。

## 第二步：建立统一风格

设置画布尺寸、内边距、圆角、阴影与内描边。选择纯色、渐变、内置图片背景，或使用自己的本地背景图。通过箭头、步骤编号和放大镜解释重点；常用配置可保存为本地风格预设。


## 第三步：导出完整画面

需要透明画布时选择 PNG；还可选择 JPG、WebP 或 AVIF。JPG 和 WebP 会将透明部分填白。界面缩放只改变观看大小，导出倍率才改变最终像素尺寸；下载前请检查画布尺寸和格式。
