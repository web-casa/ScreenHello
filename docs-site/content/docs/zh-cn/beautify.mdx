## 第一步：放入图片或直接新建卡片

点击选择图片、拖入欢迎区、粘贴剪贴板图片，或直接点击首屏快捷入口创建代码卡片（14 种离线语法高亮、6 套主题、行范围高亮与 +/- Diff 模式）、文本/社交卡片（社交帖子、金句海报、更新日志）或打开 18 套场景模板库。截取屏幕需要浏览器授权；试用示例会按屏幕宽度按需加载竖版或横版示例。

### 最多 12 个图层与显隐切换

一个项目最多容纳 12 个图片或卡片图层。每个图层各自保留位置、尺寸与外观设置，并可通过图层列表的眼睛按钮临时隐藏或显示，隐藏图层不参与交互与导出，且完整纳入撤销栈。

### 快捷键

不离开键盘就能操作编辑器。表中 Ctrl 在 macOS 上对应 Command。

| 操作 | 快捷键 |
| --- | --- |
| 打开项目 | Ctrl + O |
| 保存项目 | Ctrl + S |
| 另存项目 | Ctrl + Shift + S |
| 打开导出 | Ctrl + Shift + E |
| 复制成品图 | Ctrl + C |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z |
| 删除所选 | Delete / Backspace |
| 放大 | Ctrl + + |
| 缩小 | Ctrl + - |
| 适应画面 | Ctrl + 0 |

> 在文本框中输入时快捷键不生效，不会打断你正在编辑的文字。

## 第二步：建立统一风格与场景模板

设置画布尺寸（内置 1.618:1 黄金比例、OG 1200×630、Product Hunt、小红书、LinkedIn 等预设）、内边距、圆角、阴影与内描边。选择纯色、渐变、内置图片背景或自己的本地背景图，或直接套用 18 套内置场景模板（保留原图且一步撤销）。支持文字水印与本机压缩 &lt;= 64 KiB 的图片/Logo 水印（九宫格或平铺），并可用箭头、步骤编号和放大镜解释重点；常用配置可保存为本地风格预设。


## 第三步：导出静态图或循环动图

需要透明画布时选择 PNG；还可选择 JPG、WebP 或 AVIF，JPG 和 WebP 会将透明部分填白。如需在产品发布或社媒展示动态效果，可从「文件 → 导出动图」预览 5 种无缝循环微动画并在本机编码 GIF89a 或 WebM。界面缩放只改变观看大小，导出倍率才改变最终像素尺寸；下载前请检查画布尺寸和格式。
