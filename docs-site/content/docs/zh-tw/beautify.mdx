## 第一步：匯入圖片

選擇檔案、拖曳至歡迎區或貼上剪貼簿圖片。擷取螢幕需要瀏覽器授權。範例按鈕依點擊時視窗寬度載入手機直式截圖或平板、電腦適用的橫式截圖。

### 最多 12 張圖片

一個專案最多容納 12 張圖片。每張各自保留位置、尺寸與外觀設定。

### 快速鍵

不離開鍵盤就能操作編輯器。表中 Ctrl 在 macOS 上對應 Command。

| 操作 | 快速鍵 |
| --- | --- |
| 開啟專案 | Ctrl + O |
| 儲存專案 | Ctrl + S |
| 另存專案 | Ctrl + Shift + S |
| 開啟匯出 | Ctrl + Shift + E |
| 複製成品圖 | Ctrl + C |
| 復原 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z |
| 刪除選取 | Delete / Backspace |
| 放大 | Ctrl + + |
| 縮小 | Ctrl + - |
| 符合畫面 | Ctrl + 0 |

> 在文字框中輸入時快速鍵不會生效，不會打斷你正在編輯的文字。

## 第二步：統一風格

設定畫布尺寸、內距、圓角、陰影與內框線。選擇純色、漸層、內建背景或自己的圖片，以箭頭、步驟編號與放大鏡說明重點。常用設定可儲存為本機風格預設。


## 第三步：匯出完整畫面

需要透明畫布時選擇 PNG，也可匯出 JPG、WebP 或 AVIF。JPG 與 WebP 將透明部分填白。介面縮放只改變檢視大小，匯出倍率才改變最終像素尺寸；下載前請確認格式與畫布。
