## 第一步：匯入圖片或直接建立卡片

選擇檔案、拖曳至歡迎區、貼上剪貼簿圖片，或直接點擊首頁快捷入口建立程式碼卡片（14 種離線語法高亮、6 套主題、行範圍高亮與 +/- Diff 模式）、文字/社群卡片（社群貼文、金句海報、更新日誌）或開啟 18 套場景範本庫。擷取螢幕需要瀏覽器授權；範例按鈕依視窗寬度載入直式或橫式範例。

### 最多 12 個圖層與顯隱切換

一個專案最多容納 12 個圖片或卡片圖層。每個圖層各自保留位置、尺寸與外觀設定，並可在圖層清單點擊眼睛按鈕暫時隱藏或顯示，隱藏圖層不參與互動與匯出，且支援復原與重做。

### 快速鍵

不離開鍵盤就能操作編輯器。表中 Ctrl 在 macOS 上對應 Command。

| 操作 | 快速鍵 |
| --- | --- |
| 開啟專案 | Ctrl + O |
| 儲存專案 | Ctrl + S |
| 另存專案 | Ctrl + Shift + S |
| 開啟匯出 | Ctrl + Shift + E |
| 複製成品圖 | Ctrl + C |
| 復原 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z |
| 刪除選取 | Delete / Backspace |
| 放大 | Ctrl + + |
| 縮小 | Ctrl + - |
| 符合畫面 | Ctrl + 0 |

> 在文字框中輸入時快速鍵不會生效，不會打斷你正在編輯的文字。

## 第二步：統一風格與場景範本

設定畫布尺寸（內建 1.618:1 黃金比例、OG 1200×630、Product Hunt、小紅書、LinkedIn 等預設）、內距、圓角、陰影與內框線。選擇純色、漸層、內建背景或自己的圖片，或直接套用 18 套場景範本（保留原圖且一步復原）。支援文字與本機壓縮 &lt;= 64 KiB 的圖片/Logo 浮水印（九宮格或平鋪），並以箭頭、步驟編號與放大鏡說明重點；常用設定可儲存為本機風格預設。


## 第三步：匯出靜態圖或循環動圖

需要透明畫布時選擇 PNG，也可匯出 JPG、WebP 或 AVIF（JPG 與 WebP 將透明部分填白）。如需動態展示，可透過「檔案 → 匯出動圖」預覽 5 種無縫循環微動畫並在本機編碼 GIF89a 或 WebM。介面縮放只改變檢視大小，匯出倍率才改變最終像素尺寸。
