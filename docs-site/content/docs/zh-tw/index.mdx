## 從截圖到完整展示圖

選擇本機圖片、貼上剪貼簿圖片，或試用內建範例。加入留白、背景、瀏覽器外框與標註，製作產品更新、操作教學或社群貼文。圖片在你的裝置處理，不需要帳號，也沒有雲端同步。


## 編輯完成，專案也能帶走

畫布最多可編排 12 張圖片，支援復原操作及儲存可繼續編輯的 .screenhello 專案。專案檔是主動儲存的備份；瀏覽器自動草稿是另一份本機副本，可能隨網站資料清除而遺失。


## Web 功能與發佈狀態

支援 PNG、JPG、WebP 與 AVIF 匯出，可在下載前比較壓縮預覽。這裡介紹 Web 編輯器；桌面版仍是測試候選，Chrome/Edge 擴充功能仍在規劃中，並非正式下載項目。 AVIF 僅提供標準匯出，不提供品質調節或壓縮預覽。
