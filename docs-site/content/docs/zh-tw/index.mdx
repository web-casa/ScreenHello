## 從截圖到完整展示圖

選擇本機圖片、貼上剪貼簿圖片、試用內建範例，或直接從首頁建立程式碼卡片、文字/社群卡片並套用 18 套場景範本。加入留白、背景、3D 透視、瀏覽器外框、文字或圖片 Logo 浮水印與標註，製作產品更新、操作教學或社群貼文。所有運算都在你的裝置完成，不需要帳號也沒有雲端同步。


## 編輯完成，專案也能帶走

畫布最多可編排 12 個圖層，支援圖層眼睛顯示/隱藏切換、完整復原/重做，並儲存可繼續編輯的 .screenhello 專案（保留程式碼/文字卡片、3D 透視與 Logo 浮水印設定）。專案檔是主動儲存的備份；瀏覽器自動草稿是另一份本機副本，可能隨網站資料清除而遺失。


## Web 功能與發佈狀態

支援 PNG、JPG、WebP 靜態匯出與壓縮預覽，支援標準 AVIF 匯出，並支援 5 種無縫循環微動畫的本機 GIF89a（以及瀏覽器原生支援的 WebM）動圖匯出。這裡介紹 Web 編輯器；桌面版仍是測試候選，Chrome/Edge 擴充功能仍在規劃中，並非正式下載項目。AVIF 僅提供標準匯出，不提供品質調節或壓縮預覽。
