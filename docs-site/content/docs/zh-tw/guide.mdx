## 1. 開啟範例、匯入圖片或建立卡片

點擊本頁的「開啟編輯器」，再選擇畫布中央的範例按鈕，或直接點擊首頁「程式碼卡片」「文字卡片」「場景範本」快捷入口。使用自己的截圖時點擊「選擇圖片」選取本機檔案，內容顯示於中央畫布後再繼續。


## 2. 設定背景、外框、3D 視角與浮水印

在右側「背景」選擇純色、漸層或圖片，調整留白、圓角、陰影與文字或圖片 Logo 浮水印，並在圖層清單以眼睛按鈕切換顯隱；在左側設定畫布尺寸、瀏覽器外框、3D 透視預設或瀏覽 18 套場景範本。需要時以底部工具加入標註。

## 3. 確認尺寸並下載靜態圖或動圖

點擊頂部匯出按鈕，在匯出面板選擇 PNG、標準匯出及 1× 倍率，確認最終像素尺寸後下載。如需循環動圖，開啟「檔案 → 匯出動圖」預覽並本機匯出 GIF89a 或 WebM。畫布縮放不改變輸出尺寸；2× 倍率會讓寬高各加倍。

## 4. 儲存可繼續編輯的專案

在「檔案」選單儲存 .screenhello 專案檔。下載的圖片或動圖是成品，專案檔才保留圖層顯隱、程式碼/文字卡片、3D 透視與 Logo 浮水印等可編輯內容。之後透過檔案選單開啟該專案檔即可繼續編輯。


## 備份專案，不只依靠草稿

透過檔案選單儲存專案或另存新檔，再以開啟專案復原。草稿與最近專案在目前瀏覽器中，不在雲端。清除網站資料前先儲存專案檔；更換裝置時請自行傳輸，不會自動同步。


## 離線與疑難排解

編輯器顯示離線已就緒後，已快取的核心可離線重開。未用過的背景、裝置與編碼器可能仍需首次連線載入。這些指南不屬於離線編輯器快取，需要網路。擷取或剪貼簿權限被拒時可使用本機檔案；匯出超限請降低尺寸或倍率。
