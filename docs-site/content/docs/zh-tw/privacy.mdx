## 哪些工作在本機完成？

匯入圖片、螢幕截圖、編輯、程式碼與文字卡片渲染、3D 透視轉換、自訂 Logo 浮水印（&lt;= 64 KiB）與社群卡片頭像（&lt;= 32 KiB）壓縮，以及圖片壓縮與 GIF89a/WebM 動圖編碼皆在你的裝置瀏覽器或本機 Web Worker 完成。本應用沒有圖片上傳後端、雲端帳號或雲端同步。本機優先並不表示載入網站完全沒有網路請求。


## 儲存與請求哪些資料？

專案、草稿與預設可存於 IndexedDB（包含你主動匯入的本機頭像或浮水印圖片資料）；語言與外觀偏好儲存在本機。瀏覽器按需請求本站程式、圖示、背景與編碼資源。託管服務可能處理 IP 位址及瀏覽器標識等一般存取資料；此原始碼版本不加入分析 SDK、廣告像素或工作階段錄影。


## 刪除與遷移

在本機資料庫管理草稿、預設與最近專案，或透過瀏覽器設定清除本站資料。先儲存要保留的 .screenhello 檔案。清除瀏覽器資料不會刪除已下載至裝置的檔案；外部原始碼連結會離開本站，適用目標網站規則。
