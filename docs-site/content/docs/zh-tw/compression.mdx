## 無損不等於品質 100

PNG 無損最佳化保留像素，但不保證檔案變小。有損減色支援 256、128 或 64 色，可能改變漸層與半透明陰影。WebP 有獨立真無損模式；JPG、WebP 品質滑桿設為 100 仍不等於無損。WebP 編碼前會將透明區填白。 AVIF 僅提供標準匯出，不提供品質調節或壓縮預覽。

### 標準、無損與有損

標準匯出使用對應格式的預設編碼設定。PNG 和 WebP 提供無損模式；JPG 和 WebP 提供可調品質的有損模式。AVIF 僅提供標準匯出，沒有品質控制或壓縮預覽。

### 會遇到的上限

以下數值由編輯器在開始下載前強制檢查。

| 操作 | 上限 |
| --- | --- |
| 應用內完整預覽 | 1,048,576 像素（約 1 MP） |
| 壓縮下載 | 4,194,304 像素（約 4 MP），最長邊 8192 像素 |
| AVIF 匯出 | 4,194,304 像素，僅標準匯出 |
| PNG 調色盤壓縮 | 256、128 或 64 色 |
| 有損品質預設 | JPG / WebP: 90 / 80 / 60 |
| 匯出倍率 | 1x、2x 或 3x |
| 壓縮逾時 | 30 秒 |

> AVIF 僅提供標準匯出：沒有品質控制，也沒有壓縮預覽。

## 比較相同畫面

開啟匯出並產生預覽，在相同尺寸的標準匯出與壓縮結果間切換，以 100% 查看細節和實際位元組大小。參照是編輯後的完整畫面，不是匯入原圖；變大的結果也會如實顯示。有效預覽下載使用已產生的同一份資料。


## 上限與本機處理

AVIF 僅提供標準匯出，不提供品質調節或壓縮預覽。 PNG/JPG/WebP 壓縮下載最多 4,194,304 像素；PNG/JPG/WebP 完整預覽最多 1,048,576 像素；無法預覽不等於無法下載。標準 PNG/JPG/WebP 最多 16,777,216 像素，標準 AVIF 最多 4,194,304 像素，單邊上限 8192 像素。超限請降低畫布或倍率。編碼資源首次從本站載入，於本機執行；批次最多 12 張，成功結果下載為 ZIP。
