## De captura a imagen de presentación

Abre una imagen local, pégala desde el portapapeles o prueba el ejemplo. Añade espacio, fondos, marcos y anotaciones para novedades de producto, tutoriales o publicaciones. Las imágenes se procesan en tu dispositivo, sin cuenta ni sincronización en la nube.


## Conserva un proyecto editable

Organiza hasta 12 capas de imagen, deshaz cambios y guarda un archivo portátil .screenhello. Ese archivo es tu copia de seguridad. Los borradores automáticos del navegador son copias locales independientes que pueden desaparecer al borrar los datos del sitio.


## Funciones y estado de publicación

Exporta PNG, JPG, WebP o AVIF y compara una vista previa de compresión antes de descargar. Estas páginas describen el editor web. Las versiones de escritorio siguen en pruebas y la extensión para Chrome/Edge está prevista, no disponible como descarga definitiva. AVIF solo ofrece exportación estándar, sin control de calidad ni vista previa de compresión.
