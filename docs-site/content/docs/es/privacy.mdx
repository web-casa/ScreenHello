## ¿Qué se procesa localmente?

Las imágenes importadas, capturas, edición y compresión se procesan en el navegador de tu dispositivo. La aplicación no tiene servidor de subida de imágenes, cuentas en la nube ni sincronización. Procesamiento local no significa que cargar el sitio no genere solicitudes de red.


## ¿Qué se guarda o solicita?

Proyectos, borradores y estilos pueden almacenarse en IndexedDB; idioma y apariencia se guardan localmente. Código, iconos, fondos y codificadores se solicitan según se necesitan. El proveedor de alojamiento puede tratar metadatos habituales como IP e identificador del navegador. Esta versión del código no añade SDK de analítica, píxeles publicitarios ni grabación de sesiones.


## ¿Cómo borro o traslado mis datos?

Gestiona borradores, estilos y proyectos recientes en la biblioteca local o borra los datos del sitio desde el navegador. Guarda antes los archivos .screenhello que quieras conservar. Esto no elimina archivos ya descargados al dispositivo. Los enlaces externos al código fuente llevan a sitios con sus propias políticas.
