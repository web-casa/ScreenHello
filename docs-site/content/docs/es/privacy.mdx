## ¿Qué se procesa localmente?

Las imágenes importadas, capturas, tarjetas de código y texto, perspectiva 3D, marcas de agua con logotipo (&lt;= 64 KiB) y avatares (&lt;= 32 KiB), así como la compresión de imágenes y la codificación GIF89a/WebM se ejecutan en el navegador o Web Worker local. No hay servidor de subida, cuentas en la nube ni sincronización.


## ¿Qué se guarda o solicita?

Proyectos, borradores y estilos pueden almacenarse en IndexedDB (incluidos los datos locales de avatar o logotipo que añadas); idioma y apariencia se guardan localmente. Código, iconos, fondos y codificadores se solicitan según se necesitan. Esta versión no añade SDK de analítica, píxeles publicitarios ni grabación de sesiones.


## ¿Cómo borro o traslado mis datos?

Gestiona borradores, estilos y proyectos recientes en la biblioteca local o borra los datos del sitio desde el navegador. Guarda antes los archivos .screenhello que quieras conservar. Esto no elimina archivos ya descargados al dispositivo. Los enlaces externos al código fuente llevan a sitios con sus propias políticas.
