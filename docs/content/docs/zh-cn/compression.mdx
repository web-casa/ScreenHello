## 无损，不等于质量调到 100

PNG 无损优化保留像素，但不保证文件变小。有损减色可选择 256、128 或 64 色，可能改变渐变和半透明阴影。WebP 有独立的真无损模式；JPG、WebP 的质量滑杆即使为 100 也不等于无损。WebP 在编码前会将透明部分填白。 AVIF 仅提供标准导出，不提供质量调节或压缩预览。

### 标准、无损与有损

标准导出使用对应格式的默认编码设置。PNG 和 WebP 提供无损模式；JPG 和 WebP 提供可调质量的有损模式。AVIF 仅提供标准导出，没有质量控制或压缩预览。

### 会遇到的上限

以下数值由编辑器在开始下载前强制检查。

| 操作 | 上限 |
| --- | --- |
| 应用内完整预览 | 1,048,576 像素（约 1 MP） |
| 压缩下载 | 4,194,304 像素（约 4 MP），最长边 8192 像素 |
| AVIF 导出 | 4,194,304 像素，仅标准导出 |
| PNG 调色板压缩 | 256、128 或 64 色 |
| 有损质量预设 | JPG / WebP: 90 / 80 / 60 |
| 导出倍率 | 1x、2x 或 3x |
| 压缩超时 | 30 秒 |

> AVIF 仅提供标准导出：没有质量控制，也没有压缩预览。

## 比较同一画面，而不是不同的原图

打开导出面板并生成预览，可以在同尺寸标准导出与压缩结果间切换，以 100% 查看细节和实际字节大小。参照是编辑后的完整画面，不是导入原图；结果变大也会如实显示。下载有效预览时使用已经生成的同一份数据。


## 处理上限与离线条件

AVIF 仅提供标准导出，不提供质量调节或压缩预览。 PNG/JPG/WebP 压缩下载最多 4,194,304 像素；PNG/JPG/WebP 完整预览最多 1,048,576 像素；不能预览不等于不能下载。标准 PNG/JPG/WebP 最多 16,777,216 像素，标准 AVIF 最多 4,194,304 像素，单边均不超过 8192 像素。超限需降低画布尺寸或倍率。编码资源首次从本站加载，随后在本机处理；批量处理最多 12 张，成功结果打包为 ZIP 下载。
